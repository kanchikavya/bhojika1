Food Fiesta – Restaurant Management System
Project Overview
Food Fiesta is a Restaurant Management System developed to manage and organize common restaurant operations through an interactive dashboard.

The system provides modules for managing users, orders, payments, returns, refunds, complaints, and customer feedback.

Install MySQL.

Configure the MySQL username, password, and database name in the Python backend.

Start the Python application.

Open the frontend in a browser.
